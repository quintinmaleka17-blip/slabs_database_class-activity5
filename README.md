1) ER Components:
_________________

ENTITY- Is a real world object or person that can be identified and stored in a database
RELATIONSHIP- Describes how two or more entities are connected
ATTRIBUTE- An Attribute is a characteristic or property of an entity

2) Data model levels:
_____________________

The Conceptual Data Model provides a high-level view of the business requirements and data 
relationships. It focuses on entities, attributes, and relationships without considering 
technical implementation details. While pyshical data model focuses on how the database will
actually be implemented in a specific database.
